SYN-ARCH1: The controller has 4 modes (M1, M2, M3, Final), reads 3 real-valued sensor readings, and issues a combined linear/angular velocity command. It starts in M1.
SYN-T1: In mode M1, on EndTask the controller enters Final and commands zero velocity.
SYN-T2: In mode M1, on Advance when reading1 is at most threshold1, the controller enters M2 and commands forward velocity.
SYN-T3: In mode M1, on Retreat when reading1 exceeds threshold1, the controller enters M1 and commands zero velocity.
SYN-T4: In mode M1, a Tick leaves the controller in M1.
SYN-T5: In mode M2, on EndTask the controller enters Final and commands zero velocity.
SYN-T6: In mode M2, on Advance when reading2 is at most threshold2, the controller enters M3 and commands forward velocity.
SYN-T7: In mode M2, on Retreat when reading2 exceeds threshold2, the controller enters M1 and commands zero velocity.
SYN-T8: In mode M2, a Tick leaves the controller in M2.
SYN-T9: In mode M3, on EndTask the controller enters Final and commands zero velocity.
SYN-T10: In mode M3, on Advance when reading3 is at most threshold3, the controller enters M1 and commands forward velocity.
SYN-T11: In mode M3, on Retreat when reading3 exceeds threshold3, the controller enters M2 and commands zero velocity.
SYN-T12: In mode M3, a Tick leaves the controller in M3.
SYN-T13: In mode Final, a Tick leaves the controller in Final.
